# שליו זהבי | אלומיניום וזכוכית

אתר תדמית בעברית לשליו זהבי מנתניה. האתר מציג את תחומי העבודה, צילום מהשטח, שעות פעילות ודרכי פנייה בטלפון ובוואטסאפ.

[פתיחת האתר](https://ic3cr1pt.github.io/shalev-zehavi-aluminium/) · [סרטון הדגמה במחשב ובטלפון](https://ic3cr1pt.github.io/shalev-zehavi-aluminium/demo/walkthrough.mp4) · 38 שניות · Full HD

## תצוגה מקומית

מתיקיית המאגר מריצים `python3 -m http.server 8000` ופותחים בדפדפן את [התצוגה המקומית](http://localhost:8000/). האתר סטטי וכל התמונות והגופנים מוגשים מקומית.

## מקורות

פרטי העסק וצילום המרפסת לקוחים מעמוד העסק באיזי. רשימת השירותים מסתמכת גם על רישום העסק ב־B144. שלוש ההדמיות האדריכליות נוצרו ב־Kie.ai להמחשת תחומי העבודה. [איזי](https://easy.co.il/page/10142239) · [B144](https://www.b144.co.il/b144_sip/401D0D1A4370655D4115041140/)
